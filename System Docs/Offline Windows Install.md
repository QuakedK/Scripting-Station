# Offline Windows Install

1. Download your Windows ISO.

ISO Websites: [RG-Adguard](https://files.rg-adguard.net/version/f0bd8307-d897-ef77-dbd6-216fefbe94c5), [MAS Windows Downloader](https://massgrave.dev/genuine-installation-media), [OS.Click](https://os.click/en).

---

2. Download [Pause Windows Updates](https://github.com/QuakedK/Downloads/blob/main/Pause%20updates%20until%20the%20year%203000.reg).

Can be saved in you USB!

---

3. Burn the ISO. (Eg: [Rufus](https://rufus.ie/en/), [Ventoy](https://www.ventoy.net/en/download.html), etc)

Example: [Quaked Guide](https://youtu.be/iO6n63TWv-E) and [Chris Titus Rufus Guide](https://youtu.be/PYOsevW3KdA?si=TXlkbaY5YiDFsnRW&t=1381).

---

4. Do the [Offline Account Method](https://youtu.be/VOtOEEGxbu4?si=Q9WdHbVFJQExuPk8).
   
Important: Make sure you don't connect to ethernet/Wifi.

---

5. Run the [Pause Windows Updates](https://github.com/QuakedK/Downloads/blob/main/Pause%20updates%20until%20the%20year%203000.reg) once in Windows.

Important: Make sure you don't connect to ethernet/Wifi yet.

---

6. Restart your PC.

---

7. Connect to Ethernet/Wi-Fi.

---
