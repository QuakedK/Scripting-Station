# Usage
Quickly download your **Code Snippets, View System Docs and Learn!** The idea of this repository is to gather all of my tweaking, coding, batch and system knowledge into one big place.
Althought I might not have the best docs and information based github, hopefully I'm able to help other learn easily without sophisticated language or gatekept information.

# Folders
[Scripts](https://github.com/QuakedK/Scripting-Station/tree/main/Scripts) - (Quaked) Created **Batch Code snippets** and example code for use.

[System Docs](https://github.com/QuakedK/Scripting-Station/tree/main/System%20Docs) - (Quaked) Created **System Docs** going over various system related thing's he's learned or wanted to document.

[Packs](https://github.com/QuakedK/Scripting-Station/tree/main/Packs) - (Quaked) Created **Packs** containing files, applications for guides.
